# Security Incident Response
Any suspected security incident must be reported to the security hotline within 1 hour. A SEV1 incident requires an initial response within 15 minutes and an executive update every 2 hours. Evidence must be preserved and never deleted. See [[data-retention]] and [[password-policy]].
