# Returns Process
Every return needs a Return Merchandise Authorization (RMA) number. Items must ship back within 14 days of the RMA being issued. Opened electronics carry a 15 percent restocking fee. Product identifiers use the [[sku-catalog]] format and refunds follow the [[refund-policy]].
